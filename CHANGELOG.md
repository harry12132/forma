# Changelog

## 1.0.0 - 2026-10-19

First early release milestone.

- Added form primitives: input, textarea, checkbox, select, submit, and success.
- Bound form controls to same-named declared state values.
- Added equality-based conditional rendering with the `when` block.
- Added accessible field styling, native browser validation, and a client-side `forma:submit` event.
- Expanded the showcase and language reference.
- Added regression tests for supported form syntax and invalid controls.
- Set package version to 1.0.0 and documented the MIT licence.

### Scope notes

Forms do not submit data to a server. A trusted backend is required for production data collection. Routing, general expressions, loops, and a package ecosystem remain out of scope for this early release.
